# CISC181-computer-science-ii-homework
Completion Timeline for CISC181: February to May 2024
Last Updated on GitHub: February 21, 2026

This repository contains my completed homework assignments for CISC181: Introduction to Computer Science II at the University of Delaware College of Engineering Department of Computer and Information Sciences. I completed this course in the Spring of 2024, with Dr. Bart being the course instructor. The purpose of this course was to continue to teach introductory computer science topics to students, as started in CISC106/CISC108: Introduction to Computer Science I. 

Over the course of the semester, there were eight different homework assignments for students to complete. Each homework received its own folder within this repository and had specific concepts that students were supposed to learn. For example, Homework 2 dealt with loops and arrays, Homework 4 dealt with methods and mutation, Homework 6 involved polymorphism, and Homework 8 introduced HTML and CSS.

TypeScript was the object oriented programming language used for these homework assignments, with a little work in HTML and CSS within the 8th homework assignment. Many of the files and some of the code was provided by Dr. Bart before students started their work. The 'src' folders within each homework folder contain the work that students completed.
